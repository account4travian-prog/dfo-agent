# C1: Character creation flow and races
Commit: 0df2d87eb · Researcher: Codex · Date: 2026-10-21

## Player-facing summary
- Character creation is a staged wizard; it begins with race and ends with a summary before the character enters play. (`src/ui/chargen.js:90-122` `STATES`)
- You choose a race and gender before class; class can be selected from a list, generated from answers, or built custom. (`src/ui/chargen.js:90-122` `STATES`; `src/ui/chargen.js:102-120` wizard order comments)
- Biography questions follow class selection and can change starting character details. (`src/systems/chargenSession.js:174-195` `applyCreationExtras`; `src/ui/chargen.js:93-120` `STATES`)
- The selected race determines the race ID, race-specific art and body morphology. (`src/systems/races.js:34-45` `RACES`; `src/systems/races.js:88-111` `build`, `RACE_TEMPLATES`)
- Race does not set the chargen attribute roll: attributes begin from the selected career's base attributes, then each receives a 0–10 roll and a shared 6–14-point pool. (`src/systems/chargen.js:17-23` rules; `src/systems/chargen.js:58-63` `rollStats`)
- Only Breton, Nord and High Elf have racial resistance/immunity flags in the live race table. (`src/systems/races.js:62-85` `RACE_EFFECT_FLAGS`)

## Rules and numbers

### Creation flow
- The wizard state order is race → gender → class method/questions/list or custom class → biography method/questions → name → face → stats → skills → reflexes → summary → done. (`src/ui/chargen.js:120-122` `STATES`)
- Class method is the branch point: the class question route and generated-class route are separate from the list route. (`src/ui/chargen.js:102-120` wizard-order comments)
- Race selection precedes gender in this port; the class-choice screens follow gender. (`src/ui/chargen.js:90-112` `ChargenFlow` order notes)
- Race ID values: Breton 1, Redguard 2, Nord 3, Dark Elf 4, High Elf 5, Wood Elf 6, Khajiit 7, Argonian 8. (`src/systems/races.js:32-37` `RACES`)
- The default race when the race field is absent is Breton (ID 1); this is the fallback in character application, not a visible-screen default guarantee. (`src/systems/chargen.js:251-255` `applyCharacter`)
- The UI's race template list is ordered Breton, Redguard, Nord, Dark Elf, High Elf, Wood Elf, Khajiit, Argonian. (`src/systems/races.js:110-115` `RACE_TEMPLATES`, `RACE_KEYS`)
- The face picker uses indices 0–9 for each race/gender face set. (`src/systems/races.js:19-20,47` `FACES_PER_RACE`; `src/ui/chargen.js:178-184` face index)
- Eight attributes each receive the career base plus a random inclusive 0–10; the shared bonus pool is randomly 6–14 points. (`src/systems/chargen.js:17-23,50-63` `rollStats`)
- The chargen attribute screen allows manual allocation after rolling; each adjustment moves one point between the stat and remaining pool, with 10–75 bounds. (`src/ui/chargen.js:798` `stat allocation`; `src/systems/customClass.js:19-23` `FREE_EDIT_MIN`, `FREE_EDIT_MAX`)
- Reflexes default to Average (index 2); the picker offers five levels: Very High, High, Average, Low and Very Low. (`src/ui/chargen.js:206-209` default; `src/ui/chargenArt.js:318-319` `PLAYER_REFLEXES`, `REFLEX_COUNT`)

### Races

The source race table defines these race flags. No race-specific attribute modifier is applied by the chargen stat roller; see `rollStats` above. “No flag” means the race table initializes the four effect channels and special ability field to zero. (`src/systems/races.js:62-85,88-108` `RACE_EFFECT_FLAGS`, `build`; `src/systems/chargen.js:58-63` `rollStats`)

| Redguard | None in the race table's chargen roll. | No racial effect flag found. | All four effect flags and `specialAbilities` default to zero. (`src/systems/races.js:102-108` `build`) |

- Effect-bit values are Paralysis 1, Magic 2, Poison 4, Fire 8, Frost 16, Shock 32 and Disease 64. (`src/systems/races.js:62-68` `RACE_EFFECT_FLAGS` comments)

- Race body morphology is Human for Breton/Redguard/Nord, Elf for Dark Elf/High Elf/Wood Elf, Khajiit for Khajiit, and Argonian for Argonian. (`src/systems/races.js:39-45` `MORPHOLOGY_OF`)

## Gates
- Character creation starts for a new character, with no character level, Renown or quest gate represented in the chargen flow. (`src/systems/chargenSession.js:67-115` `loadBiogs`, `loadClassQuestionData`, `loadCareers`; `src/ui/chargen.js:120-122` `STATES`)
- Race choice occurs at the first wizard state. (`src/ui/chargen.js:120-122` `STATES`)

## Where it shows in the interface
- The client wizard's visible sequence is represented by `ChargenFlow` states: `race`, `gender`, `classMethod`, `classQuestions`, `class`, `customClass`, `bioMethod`, `biography`, `name`, `face`, `stats`, `skills`, `reflexes`, `summary`, `done`. (`src/ui/chargen.js:120-122` `STATES`)
- The race description opens a Yes/No message box, and race description text IDs are stored alongside each race template. (`src/systems/races.js:49-60` `DESCRIPTION_ID`, `CLIP_ID` comments/table)
- The skin chooses the drawing and window treatment, while the shared `ChargenFlow` owns the same stages. (`src/ui/chargen.js:28,120-122` `isEnhanced`, `STATES`; `src/systems/chargenSession.js:24,28` `ChargenFlow`, `isEnhanced`)

## Online vs offline
- Chargen uses the same race and class flow across the dungeon and town hosts; `chargenSession.js` is the shared loader/runner. (`src/systems/chargenSession.js:1-14` shared chargen comments; `src/systems/chargenSession.js:107-115` `loadCareers`)
- Online creation forces classic leveling for new characters; Oblivion leveling is offline-only. (`src/systems/chargenSession.js:163-169` `applyHeadlessChargen` comments)
- Race attributes are not independently adjusted in the chargen stat roll; that roll uses the career attributes. (`src/systems/chargen.js:58-63` `rollStats`; `src/systems/chargen.js:242-255` `applyCharacter`)
